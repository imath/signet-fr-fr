# signet-fr_FR

## Requirements

- [Retraceur](https://retraceur.github.io/) >= 1.0.0
- [Signet](https://github.com/imath/signet) >= 1.0.0

## Description

French translation for the [Signet](https://github.com/imath/signet) Retraceur block.

## Installation

Copy all files having their names starting by the `signet-fr_FR` term and paste them into the `/wp-content/languages/plugins/` directory of your personal [Retraceur](https://retraceur.github.io/) Website.
